## About

Backend-focused full-stack developer. On the server I work mainly with Python/Django and Java/Spring Boot; on the client, React and TypeScript. I design APIs and multi-tenant systems with clear boundaries, then connect them to fast, clean interfaces. I have led the technical direction of small teams and run my own product, [Filmify](https://filmify.me), in production for over a year.

- 🔨 **Building:** Divinity, a multi-tenant CRM SaaS
- 🌱 **Exploring:** Next.js

## How I Work

- **Layered architecture.** Domain, application and infrastructure kept separate so business rules don't depend on frameworks (see [Divinity](https://github.com/Grawkles/saas_divinity)).
- **Schema and API discipline.** Versioned database migrations and documented REST APIs (Flyway and OpenAPI in [Cronos](https://github.com/Grawkles/cronos-platform)).
- **Security by default.** JWT authentication, granular role-based permissions and audit logging (see [SAGI](https://github.com/Grawkles/proyecto-formativo-sagi)).
- **Tested and reproducible.** pytest and Vitest for tests, Docker Compose for environments, GitHub Actions for CI.
